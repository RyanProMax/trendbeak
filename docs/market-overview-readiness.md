# 六项市场情绪与指数估值组件准备

本轮只准备展示组件，尚未接入页面、数据同步或生产 API。正式 client 构建不包含这两组件及任何布局测试数据；当前真实四轴视图保留，不能声称六轴已经上线。

- `ChinaSentimentRadar` 只用于 A 股：恐惧贪婪指数、RSI、市场宽度、涨跌停比、沪深指数成交额、深成相对换手率。六轴使用来源明确提供的 0–100 历史分位，原值、单位、样本窗口与真实日期分开显示。不同日期、缺失或非法分位不画假点，不补 50，不将最新观测塞入历史日期。
- `IndexValuations` 只显示指数 PB/PS 分位与原倍数，保留各行真实数据日期；没有 PE 或 PE 温度。它不是行业板块表。来源与样本窗口由已核验输入提供，不硬编码“满十年”。
- 测试只使用 `tests/market-overview-components.test.mjs` 的虚构测试值，浏览器布局夹具也仅在私有临时目录，使用 2001 年日期和“布局测试来源”，不进入业务数据或发布产物。

## 尚需的数据与使用范围

现有百分位完整 CSV 只含综合情绪值，没有首页六项原始序列和对应历史分位；现有自算 RSI14 也不能冒充来源未确认的首页 RSI。指标页另六分项的组合与用户要求不同，不替换使用。市场宽度股票池、涨跌停统计范围、RSI 口径与分位样本/ties 等尚待数据提供方核验。

新增六项及 PB/PS 数据的接口、授权和公开使用范围仍未确认；未复制来源页面整表或原始大文件，未新增抓取、凭据、数据库字段或自动任务。组件完成不等于真实数据接入。数据准备获准后仍须在独立受控任务里生成有界快照，HTTP 只读；历史导航只使用对应日期真实观测。

## 独立离线算术与已有素材

`scripts/china-factor-formulas.mjs` 仅提供受控离线算术：深成换手的“此前60日”与“含当日60日”两种显式候选、同日 000001+399001 的人民币成交额转亿元、涨停数/跌停数。窗口最多60个前值；缺数、零占位、错误指数/日期或零分母不补值。没有分位归一、调参、数据获取或页面接入，不能称原站算法。

私有既有实验素材中可复用399001收盘、f57成交额、f61换手率925日（2023年1月3日至2026年10月30日），该批成交额/换手无零占位，但不足十年。两种换手候选在末日均约1.02，不能据此冒充截图1.10。已检查的原始指数文件缺000001配对数据。另493日宽度/涨跌停计数标记代理且股票池未认证，不作为全A正式输入；8036日外部基准仍只有综合情绪值，没有指定六项的多日目标。未接入任何实验总分或修改现有生产情绪口径。
