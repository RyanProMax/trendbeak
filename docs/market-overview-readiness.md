六项市场情绪与指数估值已接入正式页面。数据由独立任务准备为 D1 响应快照；页面、API、缓存 miss 均不向供应商取数或计算历史分位。

## 指标与实际口径

CN 保留六项：百分位发布的恐贪总分、沪深300 Wilder RSI14、市场宽度、涨跌停比、沪深指数成交额、深成相对换手。RSI 来自已有腾讯行情；成交额为东方财富 000001 与 399001 同日人民币金额之和（转亿元），不是全A股票成交额；相对换手为399001当日换手率除以前60个完整交易日均值，不含当日。没有拟合参考截图的1.10。

宽度和涨跌停改用开盘红自己报告的整段日计数，来源统计池范围未披露，不能称全A，也不与原乐咕序列等价。宽度为上涨÷（上涨+下跌+平盘）；涨跌停比为报告的涨停÷跌停，跌停为0保留家数但不定义比值。未解释的分项不闭合日保守隔离，既不猜总数错误也不改为分项和：2024年10月28日ZT281而232+47=279，原响应保存在私有初始化材料；没有用其他供应商补这个空缺。旧乐咕观测保存在受控初始化前的备份，不拼入新系列。公开协议线索为 MIT 项目 https://github.com/fleetinglife/levistock 的 `levistock/market/market_emotion_kph.py`。既有历史缓存来自 https://apphis.longhuvip.com/w1/api/index.php；79个独立重叠日期及2026年10月29日的五项原始计数与现接口完全一致。保留这两个采集渠道的说明，不把它们误称乐咕。现用接口为 https://apphis.kaipanhong.com/w1/api/index.php （历史）及 https://apphwshhq.kaipanhong.com/w1/api/index.php （当日），按已验证的不同操作使用，不作失败后的绕路。乐咕历史接口HTTP403后已停止该路径。

US 六项为CNN总分、NYSE新高新低净比例、NYSE成交量McClellan Volume Summation Index、五日看跌/看涨期权比、VIX、HY/IG收益率差。总分CSV与分项JSON均经 https://github.com/whit3rabbit/fear-greed-data 社区存档取得，不称直接CNN抓取。用已有价格趋势保留动量信息，雷达选取股票参与、期权、波动率与信用环境五种分项加总分，不增加综合买卖分数，也不宣称六项相互独立。JSON `data[].y` 是原始值，不是节头的当期0–100评分。股票宽度不冒称上涨家数，HY/IG利差不替换为HY/美国国债OAS。

六轴均为独立计算的此前最多252个有效观测的midrank，至少60个样本，排除当前及未来；不是原站十年算法或CNN历史标准化得分。US期权比、VIX、信用利差反向，外侧表示更高风险偏好。原值另列，缺值不补50，雷达面积不是买卖信号。

## 有界更新与存储

沿用三字段 `market_snapshot(key,payload,updated_at)`，不新增表/字段：`overview/CN`存实际消费的640日指数、计数和分位计算状态；`overview/US`存640日分项、分位状态与源ETag/字节游标；`valuation/CODE`每指数约65–105KB存原值和已排序PB/PS排名状态（12行约1.16MB），是日更实际需要的检查点，不是预留审计表。两个大盘行只增加实际展示的有界结果，新页面使用`?view=sentiment-v1`读取预生成六轴响应；旧URL保留预生成四轴明细，兼容已打开的旧JS。旧CN解码器不认识新计数来源时，兼容投影不传这两个新分项，不能伪装成旧乐咕来源。两投影的缓存、内存键和ETag隔离，304不取正文；无旧API上的运行时转换。完整计算状态仍保留；本轮CN约183KB、US约176KB，硬上限仍300KB。原行情计算与8295条情绪历史不被辅助初始化修改。

现有 GitHub Actions 写入器串行执行。CN周一至五08:37UTC（上海16:37），US周二至六03:37UTC（对应前一美股交易日，纽约冬令22:37、夏令23:37），留出社区档案03:05UTC发布后的时间。健康检查的应到截止与这两个已配置任务对齐：上海17:00、次日03:50UTC；不是延长缓存TTL，也不更新采集时间。超过截止仍缺期继续degraded。休市按现有交易日历判断；不依赖Mac/OpenD，不增加凭据/权限。

每日CN最多2个指数五日窗口、5个日计数、12个估值16KB尾部请求；US分项一个128B条件请求，未变304直接复用，变化时最多6个32KB范围（总196736B）。源必须支持已验证的206、ETag与代际一致性；游标漂移、失去重叠、较老修订、403/429或超预算就停止该任务，保留有效快照，不回退整文件。估值日更只更新变化的原值与排序状态，不重新下载/排序十年历史。一次初始化与必要修复脱离交互，显式、有界、有私有备份；原始供应商全量文件不进仓库或构建。

运行：`node scripts/overview-job.mjs --market CN|US --remote [--dry-run]`。明确初始化使用 `--initialize PRIVATE_DIR --backup PRIVATE_FILE`，只读已核验本地材料，日更不能自动初始化。缺源失败保留前版及真实日期；先验证全部候选，检查点先提交、页面最后CAS提交；发布中断后重复运行可恢复页面，无变化不改时间戳。已有全局Actions串行队列、本机排他锁和逐行CAS；不声称跨进程内存锁。

首屏和五分钟刷新只读取当前显示市场，首次切换才读取另一市场；五分钟内反复切换复用已加载数据，直接搜索个股前补读所需大盘。页面五分钟桶与实例内存命中0D1/0上游，miss只读已准备D1字符串；不会每请求查版本。位置不同的缓存不共享，失败回退和浏览器刷新可能使可见更新时间超过五分钟，不称即时全网刷新。手动实际执行与之后自然定时执行须分别报告，干跑不算启用成功。
