# 读取、持久快照与增量更新

## 请求红线

首页、行情、情绪和健康接口不运行回填、历史指标重建、行情源刷新、后台轮询或无界重试。行情与情绪同步是独立命令，尚未配置定时执行。内存和边缘缓存仅减少数据库读取，不能代替持久历史。

- `GET /` 返回约 5 KB、有固定加载尺寸的轻壳：零 D1、零行情上游、零历史计算、零图表渲染。
- `GET /api/markets/:market?symbol=...` 用主键读取已生成视图。D1 `json_extract(payload,'$.view')` 仅返回最近 365 日日历、最多 366 个逐日技术读数和当前元数据；不把预热日线或递推状态传入 Worker/浏览器。Worker 不计算技术指标，浏览器直接展示。情绪另按市场、来源、日期过滤，最多 372 日（含七日价格滞后余量），不扫描 8,287 条全库。
- 已存在的完整 V1 展示格式继续可用，不要求版本请求头，不需要强刷或 Service Worker 迁移。`If-None-Match` 未变化返回空体 304；ETag 由行情实际提交时间及情绪实际修订时间构成，读取不会使它变成新观测。
- 未初始化标的返回 404 / `snapshot_missing`，不回源、不回填、不显示假价格。搜索仍返回最多十个真实名称/代码，并以主键查询标记是否已收录；页面显示“历史待收录”，选择失败保留原大盘。必须由操作命令初始化新标的；目前本地已准备沪深 300、标普 500、NVDA。任意新股票不是即时自动回填。
- `GET /api/markets` 返回 410 和按市场入口，零数据工作。已核对此前实际 4c00c98 客户端不调用此批量接口。
- `GET /api/sentiment/:market` 从唯一的 `sentiment_daily` 五字段表读必要范围。默认 365、最多 366 自然日；更早历史显式分段读取。逐行返回来源，CNN 社区存档和同期报道不拼成一条曲线。
- `GET /api/health` 只投影两个默认行情的日期、取回时间，报告实际年龄，不为了变健康而更新数据。
- 搜索仍允许按需搜索源请求；最多 60 字符输入、100 项源结果、10 项返回，同键合并、5 分钟缓存、失败退避。它不是行情历史初始化入口。

## 最小持久存储

沿用现有 D1 绑定 `SENTIMENT_DB`，只新增一张实际使用的表（迁移 `0003_market_snapshot.sql`）：

| 字段 | 必需用途 |
| --- | --- |
| `key` | `market/symbol` 主键，定位、去重和按标的隔离 |
| `payload` | `calculation` 保存真实日线、逐日计算值和 RSI/EMA 递推检查点；`view` 保存 HTTP 实际消费的一年展示结果。前者用于后续增量、后者避免读请求重算 |
| `updated_at` | 一次成功原子替换的时间，CAS 条件防止旧作业覆盖新作业，并用于响应 ETag；不是市场收盘时间 |

没有行情审计、批次、版本、队列、来源字典或无用预留字段。行情原发布者/渠道保留在 `view.source`，本站技术计算使用明确 `technicalSource=trendbeak_technical_v1`，不会冒充 CNN 或百分位情绪算法。情绪不复制进此表。

本地真实三行初始化：CN 640 根（2024-03-11 起）、US/NVDA 各 501 根（2024-10-31 起），均截止 2026-10-30；payload 约 0.62–0.70 MB/标的，合计约 1.94 MB。展示视图 CN 242、US 251 个交易日，实际 API 含情绪约 210 KB/市场。只占既有 D1 存储/读写额度；没有新增付费资源或凭证，也未声称账户一定有剩余免费额度。表内 JSON 上限 1.8 MB，低于 D1 单行/值 2 MB 限制；使用参数绑定，避免大 SQL 字面量超过 100 KB。[D1 限制](https://developers.cloudflare.com/d1/platform/limits/)

初始化最多 640 根，更新后检查点最多 800 根。保留有限的原起点，防止每日丢弃前缀后重置递归指标。达到 800 必须显式受控重建，不能在用户请求或普通同步中自动截断/重建。表并非永久逐时行情档案，不采集分钟线。

## 独立初始化、更新和修复

本地默认连接 `.wrangler/state`，以下命令不操作远端：

```sh
npm run market:schema
npm run market:init -- --market CN --symbol 000300.SS --file /private/reviewed/cn-normalized.json
npm run market:init -- --market US --symbol '^GSPC' --file /private/reviewed/us-normalized.json
npm run market:init -- --market US --symbol NVDA --file /private/reviewed/nvda-normalized.json
npm run market:sync -- --market CN --symbol 000300.SS --dry-run
npm run market:sync -- --market US --symbol '^GSPC'
npm run market:sync -- --market US --symbol NVDA
```

`--file` 可为已验证紧凑行情（含真实 `fetchedAt`），或原始源响应；原始文件必须附实际抓取时间 `--fetched-at <ISO-timestamp>`，不能以重放时间伪装刚抓取。无文件时独立命令只抓一次指定源，不重试、不切主机绕限流。输入文件最多 2 MB，源 HTTP 最多 512 KB、超时 8 秒。重复 `init` 先查主键，已存在直接退出：0 上游、0 计算、0 写入，连输入文件也不打开。`--dry-run` 输出窗口、请求/读写/计算行数但不写库。

日常受控更新建议在对应市场收盘后各运行一次（CN 北京时间、US 美东时间，考虑夏令时），不是每五分钟跑历史任务。目前没有创建计划或自动化，发布也不会自动启动同步。

- 腾讯参数已实际验证 `sh000300,day,,,10,qfq` 返回 10 根（2026-10-19 至 2026-10-30）；普通同步取 10 根，延误时按距上次日期取必要重叠、最多 32 根。首次初始化/明确重建才取 640。
- Yahoo 普通同步用 `range=5d&interval=1d`，超过七日、最多二十八日的中断用 `range=1mo`。既有第一方响应 `meta.validRanges` 明确列出 `5d`、`1mo`、`2y`（2026-09-30 已保存核验响应）；本次实时小窗口请求收到 429，未重试或换域绕过。因此不能宣称本轮已成功实时核验 Yahoo 增量。没有使用未经证实的 `since` 或 `period1/period2` 差量参数。Yahoo 返回的是重叠小窗口，不是严格逐条变更日志。
- 两源合并真实新日和明确近期修订；相同输入零指标重算，新日一行；此前盘中末行要先结算，多算一行。RSI/EMA 递归影响从最早修订日延续到末行；过去值无未来数据。52 周、20 日和此前最多 252 个有效分位观测仍遵守原算法。
- 至少两个完整未变价格重叠作为一致性检查；多日价格变化、源报告拆股、重叠日期删除、旧输入、超过 32 根增量、超过 28 日中断或达到 800 根均停止，保留原行，不自动全量请求。单个近期修订/补缺由正确后缀重算处理。
- 小窗口不能发现窗口外历史修订，也不能仅凭两个锚点证明所有旧数据未复权。明确复权/较早修订/长缺口时，单独审阅并运行下方受控重建；可低频安排人工检查，但没有自动任务或隐藏全量兜底。US 沿用 Yahoo `quote.close`，不混入 `adjclose`。

```sh
npm run market:rebuild -- --market US --symbol NVDA --dry-run
# 审阅后，同一显式操作去掉 --dry-run；失败保留旧快照
```

每次写入一次原子替换，`UPDATE ... WHERE updated_at=原值`；并发冲突报错不盲重试。不同实例即使误同时执行也不会覆盖较新行，但可能各自发一次上游请求；没有宣称全局分布式锁。首次新标的同键 INSERT 冲突不覆盖。

远端命令必须额外 `--remote`、明确设置现有 `CLOUDFLARE_ACCOUNT_ID`，仅使用现有环境 token 或未过期 Wrangler OAuth。缺失/过期就停止，不创建凭证、不自动登录、不改权限、不接受协议。本轮未执行任何 `--remote`、生产迁移或写入；远端参数化 D1 客户端尚未线上验证。发布前先在已授权流程中迁移同一既有库、初始化至少两个默认市场（及需要的 NVDA）、查证数据，再切换新 Worker；否则新代码会明确返回未准备状态。

## 可驱逐缓存与失败

行情内存最多 32 键，5 分钟，不使用行情边缘副本。完整视图在写入器校验；入口只检查必要身份、来源、日期和字节边界，内存保存不可变 JSON 字节。冷、到期、驱逐、独立实例都只按主键读 D1 的物化视图，零行情上游、零指标计算、零写库。

同实例同键 singleflight，最多八个进行中键。D1 失败每键退避 60 秒；已有内存视图保留实际取回时间供陈旧展示，空实例返回明确 503。没有跨实例全局去重；失效并发最多造成受限 DB 读，不会引起上游/计算风暴。

情绪快照新鲜期 5 分钟，最后成功缓存最多 7 天；失败保留同源历史。投影只在快照变化时生成，热读不重新遍历情绪。浏览器最多 6 份/2 MiB/7 天备份，旧来源不会覆盖当前 D1 情绪。页面可见时至多每五分钟检查，visibilitychange 不绕过间隔；旧 4c00 页面仍可能一分钟轮询，但只收到物化结果/304，不触发历史工作。

## 生产预览 CPU 修正

首个生产绑定预览在 2026-11-01 测得首页 39 ms、CN/US/NVDA 首次读 30/31/19 ms，虽然返回成功，仍未按此结果直接发布生产。改为构建时生成与原来逐字节一致的空壳；Worker 不再载入 React 服务端渲染。D1 中由独立写入器完整校验过的视图保持 JSON 字节，HTTP 不重新解析、逐字段遍历和全对象序列化。只拼接必要的新鲜度与独立情绪投影，情绪 JSON 按实际变更复用。私有边缘缓存换用 v2 命名空间，入站检查元数据、300 KB 上限和原生 SHA-256 校验和；校验和用于检测缓存损坏，并非签名或授权机制。没有改表或重写生产快照。

后续预览仍发现新实例日期本地化初始化的 CPU 峰值。读接口只需沪市/纽约日界，使用当前时区规则的常量时间换算；2007 年前保留 IANA 历史转换。测试对照 IANA 检查历史、闰日、UTC 午夜及夏令时切换。共享显示格式器改为真正用到时才初始化，避免 Worker 导入时加载与读取无关的格式器；页面文案与日期展示保持一致。纽约当前规则依据 [NIST](https://www.nist.gov/pml/time-and-frequency-division/popular-links/daylight-saving-time-dst)，时区法规变化时需更新规则与相应测试。

最终读链进一步收敛：行情取消可驱逐边缘副本，只保留 5 分钟、最多 32 标的的实例内不可变 JSON 字节缓存；冷/驱逐实例必定单次按主键回 D1，避免边缘全体解析或加密校验的冷 CPU 峰值。完整视图仍在独立写入器校验；读取检查版本、标的来源、日期、字节界限。情绪的市场展示投影由 D1 在明确日期/来源窗口内原生 JSON 聚合和 LAG 生成，每次最多 745 个输入、每来源最多 372 条，Worker 只接收至多两个 JSON 字符串，不逐行重新编码/验证；独立情绪行接口仍保留原来来源与范围校验。此调整不增加表、不更新历史数据、不把指标重算转到数据库。
