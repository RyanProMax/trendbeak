# trendbeak 数据链路与可靠性

## 实际链路

```mermaid
flowchart LR
  prices[腾讯证券 / Yahoo 日线] --> compute[校验与技术指标计算]
  sentiment[百分位 / CNN 当前读数转引] --> moodCache[情绪实例缓存]
  compute --> snapshot[完整行情快照实例缓存 60 秒]
  moodCache --> snapshot
  search[东方财富搜索] --> searchCache[查询实例缓存 5 分钟]
  snapshot --> api[Hono API 与 React 首屏]
  searchCache --> api
  api --> browser[可见页面每 60 秒请求]
```

浏览器请求的是同源 API。页面隐藏时跳过；恢复可见时请求；已有请求进行中时避免叠加。选中个股时还会更新对应大盘对照。服务端没有行情 Cron，缓存过期后由下一次访问触发抓取。

## 缓存和持久化

- 行情：按市场和标的，实例内 Map 60 秒；相同键的并发请求合并，成功结果才缓存。实例回收后消失，不跨实例共享。
- 情绪：A 股成功结果 1 小时，美股成功结果 5 分钟，失败空值 60 秒。
- 搜索：成功结果 5 分钟，输入等待 180 毫秒后发起请求。
- 行情接口响应声明浏览器缓存 15 秒、共享缓存 60 秒；搜索声明 60/300 秒；首页声明共享缓存 60 秒。缓存头不等于行情新鲜度承诺。
- 日线、盘中快照和分时均未写入本应用数据库或文件。快照包含历史日历与指标，不只是当天一行。
- 本站不采集分钟线或逐笔。腾讯请求 `day`，Yahoo 请求 `interval=1d`；盘中值来自正在更新的当日日线柱。
- 浏览器 localStorage 保存最近 10 条搜索；离线缓存仅保存静态图标、离线页等，不保存行情 API 数据。

## 历史覆盖与预热

价格请求保留既有来源：腾讯最多 640 条前复权日线；Yahoo 两年日线。响应历史窗口扩展为 730 自然日，保留上游真实价格，保留可用的历史上下文。当前趋势图只由四档范围改变窗口，右端锚定最新大盘日期；日历选日仅改变读数与游标。技术指标仍逐日用截至该日的前缀计算，避免未来数据进入历史值。

RSI 需要至少 15 个交易日；MA20 至少 20 个交易日；量能比需要当前完整日及此前 20 个完整日；52 周位置需要完整自然年覆盖。新股、停牌和源数据不足仍可能留空。

2026-10-29 核验的原正式版本：美股四项各有 250 个交易日，A 股四项各有 242 个交易日，仅当日盘中量能比为空。旧产品中缺失的全年曲线主要是情绪源只有一个观测，以及返回历史被截为一年的范围限制，不能笼统解释为技术指标没有数据。

美股情绪来源目前只提供带日期的当前读数及未逐日标注的比较值。CNN 官方历史入口正常请求返回 418 拒绝访问；未重试伪装请求或接入未核验镜像。全年缺口保留为空。365 自然日通常只有约 250 个交易日，不补成 365 个情绪点。

## 可靠性边界

- 行情和搜索上游请求超时为 8 秒；美股依次尝试 Yahoo 两个域名。A 股对耗时不足 2 秒的网络/5xx 暂时失败，等待 500 毫秒后最多再请求一次；完整超时、访问拒绝、429、Retry-After 以及 JSON/数据校验失败不走该快速重试。搜索没有引入重试或备用源。
- 情绪请求超时为 4 秒。失败时返回明确空值，不用技术指标替代情绪。
- 浏览器刷新失败会保留上次成功读数并提示失败；可识别为暂时请求故障的空首屏在 1.5 秒后只恢复一次，手动请求会取代该恢复；服务端已用过重试预算的失败不再触发首屏快速恢复，避免两层连续放大；访问拒绝、限流和数据校验失败不会触发这次快速恢复。持续失败仍显示不可用，不制造行情。Worker 不会在失败后返回过期快照冒充最新数据。
- 部分市场失败的首页与双市场响应使用 no-store，不将不可用状态作为正常行情共享缓存；正常行情仍沿用原缓存时间。服务端仅记录有界错误阶段、状态和耗时，不记录查询词、headers 或响应正文。
- 没有源站请求限流器、跨实例去重或持久化行情备份。公开数据接口没有本站可承诺的 SLA；不将“偶尔 200”作为可靠性证明。
- 2026-10-29 07:19:58 UTC 的生产日志捕获腾讯行情上游 HTTP 501（首次尝试 586 毫秒），同一请求经有限重试最终 200，总耗时 2018 毫秒。这证实了一类上游临时错误及该次恢复，不是所有历史 503 的根因证明。此前 654 毫秒的 A 股 503 没有保留原始上游原因；搜索间歇 503 仍未定位，不能将二者混为一因或宣称已有 SLA。

实现入口：`src/App.tsx`、`src/server/market-data.ts`、`src/server/sentiment-data.ts`、`src/lib/market-signals.ts` 与 `public/service-worker.js`。

## 图表交互与来源边界

趋势 tooltip 只按日期查真实观测，周末/休市与缺失分开显示，不取相邻日替代。四项技术指标浮层的小图使用已有日线计算结果及原单位；未引入参考站六项标准化分、权重或综合算法。D3 MonotoneX 仅用于显示经过真实点且不产生额外峰值的曲线，交易日缺口仍断开，不生成历史观测。

交互只借鉴通用十字线、图例开关和缩略范围选择理念，没有复制参考站代码、UI 或调用其内部接口。[百分位方法说明](https://baifenwei.com/methodology/)未披露六项分值的完整公式与归一化窗口；[使用条款](https://baifenwei.com/terms/)要求商业用途书面许可。既有 A 股综合情绪来源沿用不变，其商业再使用许可尚未核验；本轮未增加第三方镜像依赖或扩大数据采集。
