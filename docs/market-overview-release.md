## 存储与更新

不新增表或字段。六项的已准备历史、来源键、估值显示值和实际窗口存放在既有`CN/000300.SS`的`market_snapshot.payload.view.chinaOverview`；计算检查点只保存实际更新需要的输入。HTTP仍只读预生成响应，浏览器不计算历史分位。

现有日更继续以有界窗口更新行情、恐贪和RSI，保留辅助历史及估值的真实日期。辅助四项及估值尚未加入每日采集，不宣称自动更新。显式导入已核验小视图：

```sh
node scripts/overview-import.mjs --file /private/reviewed-view.json --remote --dry-run
node scripts/overview-import.mjs --file /private/reviewed-view.json --remote --backup /private/cn-before.json
```

输入不允许替换恐贪或RSI；无源端请求，单次至多366个展示日期、150KB输入。实写前备份原CN行，并用`updated_at`条件更新避免覆盖并发日更。重复相同视图不写入；两个US行与情绪历史不参与导入。

新版本使用独立的边缘缓存命名空间，避免发布初期命中缺少概览的旧响应；缓存仍为5分钟桶，并非即时全网共享内存。日更计划及凭据配置不变。
