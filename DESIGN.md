# trendbeak visual system

White canvas, thin separators and tabular figures remain the foundation. The brand is one continuous trend line folded into an open right-facing beak. Its outlined `trend` wordmark blends sage through muted gold to coral; `beak` is gray green. Dark-background and one-color variants preserve the same geometry. Existing market-chart colors remain; factor radars extend the palette with radius-based green–gold–coral signals. Small text uses darker related tones for legibility.

## Calendar and quotes

Keep the original heatmap, shared month axis, keyboard navigation and trading-day rules. One continuous seven-row grid spans the whole interval, including January. Cell size adapts to the available width and week count, with a 12 px minimum and horizontal scrolling for long narrow intervals. Both markets share horizontal scroll; the 188 px grid viewport stays stable during range changes. Calendar and trend render precisely the same selected natural dates; no extra calendar-year boundary cells. The market name, instrument, point value, return and actual quote date now live in the left market area; mobile presents a compact header above each market grid. There are no standalone quote blocks at the top. A selected day updates these readings exactly; closed or missing sessions remain empty. The four-level return colors use softened green and coral from the same palette.

The calendar header contains only its title and the global selected date. Selection lives in the annual heatmap and trend chart; there is no separate date picker, adjacent-date control or latest button. The return scale and closed/missing keys share one centered, wrapping legend. Price dates remain per market: a common calendar selection is never used to pretend a market has a quote.

## Trend semantics and color

On first hydration use 365 natural days on desktop, 90 on mobile. Read the responsive default once; later viewport changes never reset it. Explicit windows survive refresh and same-tab reload in guarded session storage. The navigator has independent start/end handles, whole-window panning and background click-to-center. Its extent is the union of real benchmark history; 30/90/180/365 remain latest-window shortcuts. One absolute start/end pair controls both markets, with a seven-natural-day minimum (or all available dates if fewer). User-selected historical windows survive data refresh. Calendar selection and hover update cursors and exact-date readings, never the window, source paths or index domain. Out-of-window selection has a brief state.

Emotion color encodes its Y value, not elapsed time. The scale is flat green at 0–20, then continuously blends through gray green at 40, gold at 50 and apricot at 65, reaching coral at 80–100. A user-space vertical SVG gradient shares the fixed 0–100 scale; points and tooltip values use the same sRGB interpolation. This display scale does not change either source's scoring algorithm or verbal emotion categories. Benchmark prices use a distinguishable neutral solid line and a separate point-value axis.

Trend headers contain only the market name. Curve-end labels show numeric values only; their accessible names preserve the series, actual observation date and emotion category. Historical and hovered values live in a compact reserved readout below the curve, without a repeated date; the exact inspection date stays at the cursor. They never obscure the plot or change layout. Larger fixed-pixel axis labels, dates, legends and readouts share the calendar’s typography. Missing values stay missing; a lone CNN observation is a point, never a fabricated yearly line. Emotion is not gated by whether a price bar exists on that date.

## Motion and input

Monotone curves pass through real observations and preserve extrema. A fixed scene covering the available benchmark history holds the original paths and trading-day gaps; range changes continuously transform the clipped viewport and price scale over 420 ms. No intermediate observations are synthesized, and hover does not recreate paths. Reduced motion makes the transform immediate.

Mouse clicks on the SVG interaction region have no default rectangular outline. Keyboard focus remains visible through a thin, rounded gradient stroke. Other controls keep their own focus styles. The search field rotates a small conic-gradient border layer only while hovered or focused, pauses while inactive, and is static under reduced motion.

## Signals and validation

Four radar axes retain original RSI, MA20 deviation, 52-week position and daily-return values. RSI and price position map directly; MA20 ±10% and daily return ±3% map linearly to 0–100 for display only. A radial green–gold–coral fill and stroke encode distance, with matching points and darker related value text. Missing coordinates remain absent and never form a fabricated closed area. No weights, area score or new fear/greed formula are introduced. Volume remains a backend metric, because expansion can accompany either direction. There is no radar title, repeated date, info badge, separator or permanent annotation. Both real data points and axis labels open the same temporary explanation and point highlight. Its position follows the inspected axis, preferring a free corner and flipping above/below on narrow screens; it clears the whole diamond and every raw-value label without moving layout. All chart cursors remain default; accessible names use ARIA rather than native title bubbles. Touch pins the explanation; Escape, close and outside press dismiss it.
